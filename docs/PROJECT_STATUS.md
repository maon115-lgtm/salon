# حالة مشروع مواعيد

آخر تحديث: 2026-11-09. أُوقف العمل بطلب المستخدم بعد حفظ الحالة الحالية للنقل إلى استضافة أخرى.

## المستودع

https://github.com/maon115-lgtm/salon — الفرع main.

## المكتمل

- قاعدة Supabase PostgreSQL: مشروع salon، المعرّف xbwfaczirkzgnxpqtcwb، منطقة Mumbai.
- رابط الخدمة: https://xbwfaczirkzgnxpqtcwb.supabase.co
- جداول salon_workspaces وsalon_branches ودالة salon_store منشأة، مع حماية RLS وقصر الوصول على الخادم.
- إعادة تشغيل المشروع بعد توقفه المؤقت.
- إصلاح اتصال Cloudflare Workers باستخدام redirect: manual مع رفض إعادة التوجيه.
- نجاح القراءة من Supabase ونجاح اختبار التطبيق المحلي في إنشاء فرع وحجز وحفظه في القاعدة السحابية.
- نجاح اختبار طلبَي حجز متزامنين: نجح أحدهما ورُفض الآخر بتعارض. الفرع المخفي يمنع الحجوزات.
- إزالة بيانات الاختبار المؤقتة فقط بعد الاختبار؛ لم تُنقل بيانات D1 القديمة.
- نجاح 52 حالة اختبار، وفحص TypeScript، وبناء التطبيق.

## ما لم يكتمل

- تكامل Supabase المباشر مع مستودع GitHub ونشر تغييرات الجداول تلقائيًا لم يتأكد تفعيله. رفع المصدر إلى GitHub يعمل.
- الموقع لم يُنشر لاستقبال عملاء فعليين. الاتصال المؤكد حاليًا من نسخة التطوير المحلية إلى Supabase.
- دخول التطوير المحلي يستخدم هوية اختبار؛ يجب تهيئة هوية حقيقية قبل الإنتاج.

## نقل المشروع

1. انسخ المستودع مع الاحتفاظ بقاعدة Supabase الحالية؛ لا تُعد تنفيذ ملف إنشاء الجداول فوقها.
2. أضف أسرار الخادم: DB_PROVIDER=supabase وSUPABASE_URL وSUPABASE_SECRET_KEY. المفتاح موجود في ملف .dev.vars المحلي المستبعد من Git؛ انقله عبر إعدادات الأسرار فقط، ولا ترسله في الدردشة أو تضعه في المستودع.
3. التطبيق الحالي مبني على Vinext وCloudflare Workers، ويستخدم cloudflare:workers؛ أي منصة مختلفة تحتاج تكييف بيئة التشغيل والمصادقة. رفع الملفات وحده لا يكفي.
4. إعدادات .openai/hosting.json تخص استضافة Sites السابقة، ولا تثبت وجود نشر فعّال.
5. ملف SQL طُبّق يدويًا من محرر Supabase؛ يلزم التحقق من سجل migrations ومطابقته قبل تفعيل النشر التلقائي.

## الفحوص

- npm run db:check:supabase: فحص قراءة فقط بعد ضبط أسرار الخادم.
- scripts/verify-supabase-live.mjs: اختبار سحابي اختياري ينشئ فرعًا مؤقتًا ويحذفه؛ يتطلب SUPABASE_TEST_WRITES=1 وخادم التطوير المحلي.
- تعليمات إضافية في supabase/README.md.
