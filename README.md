# مواعيد
نسخة تجريبية خاصة لفرع صالون واحد: إدارة العميلات والموظفات والخدمات والحجوزات والتقارير.

## التشغيل
npm ci
npm run dev

تسجيل الدخول المحلي عبر /signin-with-chatgpt. يعتمد تسجيل الدخول المنشور على بوابة Sites؛ يجب عدم نشر العامل مباشرة خارج هذه البوابة لأن هويات المستخدمين تأتي من ترويساتها الموثوقة.

## التحقق
node --test tests/domain.test.mjs
node tests/api.test.mjs (يتطلب خادمًا محليًا وقاعدة بيانات محلية؛ ينشئ عميلة اختبار ثم يحذفها)
npx tsc --noEmit
npm run build

## البيانات والحدود
قاعدة D1، صف مستقل لكل هوية مع رقم إصدار لمنع ضياع التعديلات المتزامنة. البيانات التجريبية افتراضية ومعلّمة بوضوح. مسح التجربة يحذف كل تعديلات التجربة أيضًا. السعة في هذه النسخة 50 موظفة و200 خدمة و2000 عميلة و10000 حجز. كل الخدمات متاحة لكل موظفة. لا توجد صلاحيات موظفين مشتركة أو فروع متعددة أو دفع أو رسائل تلقائية. قيمة الخدمات المكتملة ليست إيرادًا محصلًا أو ربحًا محاسبيًا.

## تحقق الإصدار
19 اختبار قواعد عمل و6 فحوص اتصال/حفظ مرت. تمت مراجعة منع التعارض وحفظ النموذج وإعادة التحميل في المتصفح. تسجيل الدخول المحلي محاكاة مخصصة للتطوير فقط. لا يعادل هذا تدقيق أمان مستقلًا أو اعتماد جاهزية نظام تجاري واسع.
