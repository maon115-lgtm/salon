# Project workflow

- The user-designated source repository is https://github.com/maon115-lgtm/salon.
- Use this repository for ongoing work on this project. Fetch and inspect upstream changes before editing; preserve existing work and never force-push over it.
- After completing and verifying requested changes, commit and push them to this repository unless the user asks to keep them local. Report any authentication or push blocker clearly.
- Keep credentials, environment secrets, local databases, and generated dependency/build directories out of Git.
- A GitHub push is source synchronization, not confirmation of website deployment. Report these separately.
