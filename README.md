# مواعيد
بوابة عربية لشركاء الصالونات النسائية وSpa وصالونات الحلاقة الرجالية، ومسار حجز موحد للعملاء من الرجال والنساء.

## التشغيل
npm ci
npm run dev
تسجيل الدخول المحلي عبر /signin-with-chatgpt. هوية الإنتاج تأتي من بوابة Sites الموثوقة؛ لا تنشر العامل خارجها اعتمادًا على ترويسات يرسلها المستخدم.

## المسارات والفروع
- /start اختيار مسار الشريك أو العميل.
- /partners اختيار الفئة وإضافة الفروع والتحكم بظهورها للعملاء.
- /dashboard?workspace=... لوحة فرع مستقل بخدماته وفريقه وعملائه وحجوزاته ومستخدميه.
- /explore استكشاف الفئات الثلاث واختيار الفرع والخدمة والوقت وتأكيد الحجز بعد تسجيل الدخول، ثم عرض حجوزات الحساب.
- /dashboard?legacy=1 يحافظ على الوصول لمساحة التجربة السابقة.
كل فرع جديد يبدأ فارغًا مع قوالب خدمات مناسبة للفئة غير مفعلة. لا يظهر للعملاء حتى يضيف صاحبه فريقًا نشطًا وخدمة مفعلة بسعر موجب ويختار إظهاره. الأسعار لا تُفترض تلقائيًا. يمكن للحساب إنشاء فروع في أكثر من فئة. لا يُقيّد العميل بفئة بناءً على جنسه.

## الصلاحيات
صاحب الفرع يدير تشغيله والمستخدمين. الشريك المضاف يدير التشغيل في الفرع المعني دون إدارة المستخدمين. العميل المضاف لمركز المستخدمين يقرأ ملفه المرتبط فقط؛ أما مسار الاستكشاف فيربط الحجوزات الجديدة بهوية تسجيل الدخول تلقائيًا. لا تُعرض الملاحظات الداخلية أو حجوزات الآخرين للعملاء. تعليق العضوية يمنع الوصول إلى لوحة الفرع ولا يمثل حظرًا عامًا للحساب في السوق.
الرابط يحدد الفرع ولا يمنح صلاحية بمفرده. عضوية الفرع وإذن الدخول للموقع طبقتان منفصلتان؛ إضافة مستخدم أو إظهار فرع لا يغير جمهور الموقع الخاص. لا تُرسل دعوات بريدية تلقائيًا ولا تُخزن كلمات مرور.

## البيانات والحدود
D1 يحفظ صفًا لكل مساحة مع رقم إصدار لمنع ضياع التعديلات المتزامنة، وجدولًا للفروع والملكية والفئات. الحجز يتحقق من الوقت والسعر والخدمة والفريق في الخادم، ويحفظه بتحديث مشروط لمنع حجزين متزامنين لنفس الوقت. بيانات الفروع مستقلة. سجل التدقيق يحتفظ بآخر 100 تغيير. لا يوجد دفع إلكتروني أو واتساب. المواعيد بتوقيت الرياض. هذه نسخة أولية؛ لا توجد إدارة عطلات أو صلاحيات تشغيل متعددة المستويات أو حظر عام للحسابات.

## الاختبارات

node --test tests/api.test.mjs tests/access-api.test.mjs
node tests/branches-api.test.mjs

اختبارات API تتطلب خادم التطوير وقاعدة D1 محلية مهيأة. تنشئ بيانات اختبار مؤقتة وتحذفها في النهاية دون تعديل محاكاة المصادقة. تشمل الفئات والفروع والنشر والحجز المتزامن وعزل المالك وخصوصية حجوزات العميل. الاختبارات لا تعادل مراجعة أمان مستقلة.
