# مواعيد
نسخة خاصة لإدارة مساحة صالون مشتركة، بتصميم محايد للصالونات الرجالية والنسائية.

## التشغيل
npm ci
npm run dev
تسجيل الدخول المحلي عبر /signin-with-chatgpt. بوابة Sites توفر الهوية الموثوقة في النشر؛ لا تنشر العامل خارجها اعتمادًا على ترويسات يرسلها المستخدم.

## الصلاحيات
- مسؤول المساحة: صاحب هويتها الأصلية، يدير التشغيل والمستخدمين.
- مالك الصالون المضاف: يدير التشغيل في نفس المساحة، دون إدارة المستخدمين أو مسح التجربة.
- العميل المضاف: يقرأ حجوزات ملفه فقط، دون الملاحظات الداخلية أو معلومات العملاء الآخرين. لا يغير الحجوزات من حسابه في هذا الإصدار.
- العضوية مرتبطة بالبريد الذي تؤكده بوابة تسجيل الدخول. التعليق يمنع الطلب التالي، ولا يحذف السجل أو يمسح نسخة بيانات سبق للمستخدم مشاهدتها.
- الرابط /?workspace=... يحدد المساحة ولا يمنح صلاحية بمفرده. عضوية المساحة وإذن الدخول إلى الموقع طبقتان منفصلتان. الموقع الخاص لا يصبح عامًا عند إضافة مستخدم.
- اسم الصالون في حساب المالك حقل تعريفي؛ لم تُنفذ فروع مستقلة. كل مالك مضاف يرى بيانات التشغيل في المساحة نفسها. لا ترسل دعوات بريدية تلقائيًا، ولا تُخزّن كلمات مرور.

## البيانات
D1 يحفظ صفًا لكل مساحة مع رقم إصدار لمنع ضياع التعديلات المتزامنة. مركز المستخدمين يدعم إضافة وتعديل الدور والحالة وربط العميل والبحث والتصفية ورابط الوصول. سجل تدقيق محلي بآخر 100 تغيير. لا يمكن مسح التجربة بعد إضافة مستخدمين مرتبطين. لا توجد رسائل واتساب أو دفع إلكتروني.

## الاختبارات
node --test tests/domain.test.mjs tests/access.test.mjs
node tests/api.test.mjs
node tests/access-api.test.mjs
node node_modules/typescript/bin/tsc --noEmit
npm run build

اختبارات API تتطلب خادم التطوير وقاعدة D1 محلية مهيأة. اختبار الصلاحيات ينشئ ثلاث مساحات اختبار مؤقتة ويحذفها في النهاية. يستخدم هوية المحاكاة المحلية المعلنة في ملف build/sites-vite-plugin.ts، دون تعديل محاكاة المصادقة أو تجاوزها.

القواعد: 32 اختبارًا. الاتصال والحفظ: 6 فحوص. عزل الأدوار عبر API: 6 فحوص. جرى اختبار الإضافة والتعليق وربط العميل في المتصفح ومراجعة سطح المكتب والجوال. هذه الاختبارات لا تعادل مراجعة أمان مستقلة.
